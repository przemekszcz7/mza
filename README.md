# Manufaktura ziołowa Agaty

Statyczna strona (jeden plik `index.html`) gotowa do GitHub Pages.

## Wdrożenie
1. Utwórz repozytorium na GitHubie i wgraj `index.html` oraz `README.md` do głównego katalogu (gałąź `main`).
2. Wejdź w **Settings → Pages**.
3. W sekcji **Build and deployment** wybierz **Deploy from a branch**, gałąź `main` i folder `/ (root)`, zapisz.
4. Po chwili strona będzie pod adresem `https://TWOJA-NAZWA.github.io/NAZWA-REPOZYTORIUM/`.

Zamówienia trafiają na agatapukacz@gmail.com (przyciski mailto).
